# AutoFB Bot Template

## Prerequisites

Before using this template, ensure you have:
- **Node.js** installed on your machine.
- A valid API Key from [Kaiz APIs](https://kaiz-apis.gleeze.com).

## Setup

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Heruteah/AUTOFBBOT-TEMPLATE.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd AUTOFBBOT-TEMPLATE
   ```

3. **Install dependencies**:
   ```bash
   npm install
   ```

4. **Provide your API Key**:
   - Update the `.env` file with your API key:
     ```
     API_KEY=your_api_key_here
     ```

## Usage

Run the bot with the following command:
```bash
node index.js
```

For advanced usage and customization, refer to the [documentation](docs/usage.md).
